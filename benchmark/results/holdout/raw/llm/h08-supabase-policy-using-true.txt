Suggested fix: restrict reads and writes to the row owner.

```sql
drop policy "anyone can read notes" on public.notes;
drop policy "anyone can update notes" on public.notes;

create policy "owners select" on public.notes for select to authenticated
  using (auth.uid() = user_id);

create policy "owners update" on public.notes for update to authenticated
  using (auth.uid() = user_id)
  with check (auth.uid() = user_id);
```

If notes are meant to be public, keep the select policy but only for intentionally public content. The update policy should still be owner-scoped. The insert policy on line 10 is correctly scoped, but it has no `to` clause, so you may want to add `to authenticated` there as well.
