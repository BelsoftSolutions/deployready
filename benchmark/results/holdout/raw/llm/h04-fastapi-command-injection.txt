**Suggested fix for the main issues:**

```python
import ipaddress
import re
import subprocess

HOSTNAME_RE = re.compile(r"^(?=.{1,253}$)([A-Za-z0-9](?:[A-Za-z0-9-]{0,61}[A-Za-z0-9])?)(\.[A-Za-z0-9](?:[A-Za-z0-9-]{0,61}[A-Za-z0-9])?)*$")

@app.get("/api/diagnostics/ping")
def ping(host: str, user=Depends(current_user)):
    # require admin/operator role here, per your auth model
    try:
        ipaddress.ip_address(host)
    except ValueError:
        if not HOSTNAME_RE.fullmatch(host):
            raise HTTPException(status_code=400, detail="invalid host")
    out = subprocess.run(["ping", "-c", "1", host], capture_output=True, text=True, timeout=5)
    return {"output": out.stdout}
```

Validating the host before it reaches the argument list stops both shell injection and option injection, since a valid hostname or IP cannot begin with `-`. The list form with `shell=False` removes the shell entirely, and the timeout bounds resource use.
