**Fix:** Enable RLS on both tables and add owner-scoped policies, for example:

```sql
alter table public.profiles enable row level security;
alter table public.orders enable row level security;

create policy "own profile" on public.profiles
  for all using (auth.uid() = id) with check (auth.uid() = id);

create policy "own orders" on public.orders
  for all using (auth.uid() = user_id) with check (auth.uid() = user_id);

alter table public.orders alter column user_id set not null;
```

I reviewed these files by reading them only and did not test against a live Supabase instance. The first two findings are the most serious, and the `myOrders` query is safe only once the policies above are in place.
